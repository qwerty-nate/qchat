02 — architecture

Three cages, one discipline

Alice and Bob each run an 8-qutrit circuit: ijk as a 3-qutrit state-machine register, abcde as a 5-qutrit data register. The server never crosses entanglement between cages — it relays.

Every transition above is exactly one qutrit flip — including tier crossings. That single-flip discipline is the consistency constraint that caught the errors in the original IJK table: a duplicate assignment, a malformed SEND row, an undocumented DELETE fork.

03 — encoding

04 — key exchange

Eavesdropping shows up as noise

Key establishment uses qutrit Bell states measured across two conjugate Fourier bases, once per session. An eavesdropper on the channel doesn't get caught by a rule — they get caught by the QBER spiking.

05 — the circuit

What's actually quantum here

The message chain is honest, deterministic mod-3 arithmetic — no superposition. QKD and the random-word generator are where the quantum logic lives.

# qchat_payload_circuit.py — single-flip transition check
def is_valid_transition(state_a, state_b):
    diff = [(b - a) % 3 for a, b in zip(state_a, state_b)]
    flips = sum(1 for d in diff if d != 0)
    return flips == 1  # exactly one qutrit moves, every time
